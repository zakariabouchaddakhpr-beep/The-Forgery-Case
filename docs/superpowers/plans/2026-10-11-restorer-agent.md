# Restorer Multimodal Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Restorer's single Gemini HTTP call with an n8n AI Agent that sees the plate and photograph, calls `plate_notes` and `examine_plate` tools, and remembers earlier findings.

**Architecture:** The Restorer branch inside the one merged workflow (`fcGame0000000001`) becomes: guardrail → `Restorer Agent` (Gemini chat model, Postgres chat memory, Postgres tool, workflow tool, structured output parser) → existing `Parse & Validate`. `examine_plate` calls a small sub-flow in the same workflow (Execute Workflow Trigger → read plate → one focused Gemini vision call → text). Everything is generated by `tools/build_workflows.py` and deployed with `setup.ps1`.

**Tech Stack:** n8n 2.41.4 (Docker), `@n8n/n8n-nodes-langchain` agent 3.1 / lmChatGoogleGemini 1.2 / memoryPostgresChat 1.3 / toolWorkflow 2.2 / outputParserStructured 1.3, Postgres 2.6 nodes, Python 3.13 build script, Node for JS checks.

**Spec:** `docs/superpowers/specs/2026-10-11-restorer-agent-design.md`

## Global Constraints

- Model: `models/gemini-3.8-flash` for the agent and for `examine_plate`. NOT `gemini-flash-latest`: LangChain (`@langchain/google-genai` 2.1.24) only allows images for model names starting `gemini-2`/`gemini-3` ("This model does not support images"); `-latest` currently resolves to `gemini-3.8-flash` anyway (verified 2026-10-11).
- `/webhook/turn` request and reply shape unchanged.
- Restorer never states a verdict, attribution or date; guardrail and `Parse & Validate` banned-word filter stay.
- All workflow changes in `tools/build_workflows.py`; UI edits are overwritten by `setup.ps1`.
- The project folder is NOT a git repository: there are no commit steps; each task ends with its test passing.
- Spike results (2026-10-11, throwaway workflow `fcSpike000000001`, now unpublished): passthrough binary images reach Gemini via the agent with a versioned model name; a `toolWorkflow` tool calls an Execute Workflow Trigger inside its own workflow and `{{ $json.case_id }}` in its inputs resolves to the agent's input item.

## Review Focus

1. The model passes a sloppy plate name to `examine_plate` ("X-ray", "UV light", "raking light") → normalised to a valid kind, or a plain-text error the agent can read; never a crash. (Test: Task 3, `test_examine_check_normalises_kind`.)
2. The agent returns output that does not match the findings schema (missing field, string instead of object, junk) → `Parse & Validate` takes its existing fail branch ("The Restorer could not produce a valid reading of this plate."), same behaviour as today; never a crash or a 500. (Test: Task 3, `test_parse_accepts_agent_object_and_rejects_junk`.)
3. Gemini answers 503 "high demand" mid-loop (seen live during the spike) → the agent and the examine HTTP call retry before giving up. (Test: Task 3, `test_retries_configured`.)
4. Off-topic or verdict questions ("is it a forgery?") are refused by the guardrail without any model call, even though images now travel as binary. (Test: Task 4, live refusal turn.)
5. Two players on the same case never share Restorer memory. (Test: Task 4, second session asks what was found before.)

```python
def into(target, kind):
    """Names of nodes connected to `target` with connection type `kind`."""
    return sorted(src for src, kinds in WF["connections"].items()
                  for outs in kinds.get(kind, []) for o in [outs] for c in (o or []) if c["node"] == target)


def run_js(js, input_json, refs=None):
    """Run a Code node's JS with $input / $() stubbed; returns its result."""
    prelude = ("const $input = { first: () => ({ json: %s, binary: {} }), all: () => [{ json: %s, binary: {} }] };\n"
               "const REFS = %s; const $ = n => ({ first: () => ({ json: REFS[n] }) });\n") % (
        json.dumps(input_json), json.dumps(input_json), json.dumps(refs or {}))
    out = subprocess.run(["node", "-e", prelude + "console.log(JSON.stringify((function () {\n" + js + "\n})()));"],
                         capture_output=True, text=True)
    assert out.returncode == 0, out.stderr
    return json.loads(out.stdout)
```

```python
EXAMINE_CHECK_JS = r"""// examine_plate input comes from the model: whitelist the plate and the case before any file is read.
const j = $input.first().json;
const KINDS = ['uv', 'xray', 'macro', 'raking_light'];
const CASES = %s;
// the model writes "X-ray", "UV light", "raking light plate"...: map the usual spellings, reject the rest
const MAP = { xray: 'xray', x_ray: 'xray', uv: 'uv', uv_light: 'uv', uv_fluorescence: 'uv', ultraviolet: 'uv',
  macro: 'macro', raking_light: 'raking_light', raking: 'raking_light' };
const said = String(j.kind || '').toLowerCase().trim().replace(/[\s-]+/g, '_').replace(/_plate$/, '');
const kind = MAP[said] || said;
let region = null;
try { region = JSON.parse(j.region || 'null'); } catch (e) { region = null; }
const ok = KINDS.includes(kind) && CASES.includes(j.case_id);
return [{ json: {
  ok, error: ok ? null : `Unknown plate "${j.kind}". Use one of: ${KINDS.join(', ')}.`,
  case_id: j.case_id, kind, focus: String(j.focus || '').slice(0, 200), region,
} }];"""

EXAMINE_REQUEST_JS = r"""// One focused look at one plate, for the Restorer agent's examine_plate tool.
const r = $('Examine: check').first().json;
const reg = r.region;
const box = Array.isArray(reg) && reg.length === 4
  ? ` The player's marked area is box_2d [${[1, 0, 3, 2].map(i => Math.round(reg[i] * 1000)).join(', ')}] on a 0-1000 scale.` : '';
return [{ json: {
  url: 'https://generativelanguage.googleapis.com/v1beta/models/gemini-3.8-flash:generateContent',
  request: {
    system_instruction: { parts: [{ text: 'You are a conservation technician. Describe ONLY what is physically visible on '
      + 'this simulated technical plate: density, fluorescence, brushwork, cracks, layers, retouching. No conclusions about '
      + 'authenticity, artist or date. At most 120 words. If nothing notable is in the area, say so.' }] },
    contents: [{ role: 'user', parts: [
      { inline_data: { mime_type: 'image/png', data: $input.first().json.image_base64 } },
      { text: `Plate: ${r.kind} (simulated). Look at: ${r.focus || 'the whole plate'}.${box}` },
    ] }],
    generationConfig: { temperature: 0.2, maxOutputTokens: 400 },
  },
} }];"""

EXAMINE_REPLY_JS = r"""// What examine_plate hands back to the agent: plain text, never an exception.
const chk = $('Examine: check').first().json;
if (!chk.ok) return [{ json: { text: chk.error } }];
const res = $input.first().json;
const parts = (((res.candidates || [])[0] || {}).content || {}).parts || [];
const text = parts.map(p => p.text || '').join('').trim();
return [{ json: { text: text
  ? `${chk.kind} plate, ${chk.focus || 'whole plate'}: ${text}`
  : `The ${chk.kind} plate could not be read just now (${(res.error && (res.error.message || res.error)) || 'no answer'}).` } }];"""
```
